# Skills repository

- This repository is the canonical source for the user's reusable skills. Maintain each skill in `skills/<name>/`; update its source here rather than creating divergent copies in application repositories.
- Keep generated project websites, architecture content, source snapshots and runtime captures in the target project. Moving a skill does not move its generated output.
- When adding or changing a skill, update the root README inventory, capability description and installation/usage instructions as needed.
- Keep reusable templates project-independent. Do not include analyzed project names, paths, revisions, case studies or architecture in reusable skills. Keep project-specific evidence in the analyzed project.
- Read the affected skill and its referenced resources before editing. Verify links and run changed scripts against an appropriate example. Prefer offline checks; do not invoke real model APIs for documentation validation.
- Never overwrite an installed skill or another repository's changes without inspecting them. Do not commit or push unless requested.
