# 源码分析工作台

以源码为中心组织理解，不做幻灯片。默认生成到被分析项目的 `source-guide/`，首页直接显示代码、文件树、符号、关系与讲解。项目名称、路径、符号、运行场景及结论必须从当前源码提取，不写入本技能。

## 先确定分析能力

读取项目约定、入口、语言、构建配置和模块边界。区分生产代码、测试、示例、生成文件与依赖。使用 [scripts/build.mjs](scripts/build.mjs) 为 JS/TS 建立编译器静态索引；它只读取项目，不执行项目代码。先阅读 [索引与讲解格式](references/analysis-format.md)。

优先使用项目现有 TypeScript 编译器 API。若安装版本没有 `createProgram`，可通过 `--compiler` 显式指定本机已有的兼容编译器；记录版本与差异，不降级项目依赖，不暗自下载。根配置不能代表所有子项目时，说明覆盖范围，必要时按子项目生成独立索引。

内置索引器支持 JS/TS 定义、引用、直接调用、构造调用、类型继承与导入。其他语言目前提供源码及文本搜索；需要语义分析时接入已有 LSP、编译器或 SCIP 等可靠索引，再扩展构建器与验证。不要把文本匹配标为语义引用，也不要声称已覆盖 Source Insight 的所有功能。工作台为只读快照，不包含调试、编译或重构。

## 把关键实现讲清楚

先用源码建立“入口 → 核心状态 → 外部边界 → 返回结果”的具体路径。完整阅读参与结论的实现，核对调用位置、参数、返回值、异步时机、状态所有者和错误出口。源码快照或自动索引不等于人工分析完成。

在项目 `source-guide/analysis.json` 中编写函数讲解与调用链。讲解绑定真实文件和唯一符号，说明解决的问题、调用前后数据、关键分支、状态变化、错误与取消，以及必要的设计代价。输入输出用相互对应的小样本；未执行的例子标为源码推导或教学示意。自动提取的注释与人工讲解分开展示，不为每个函数机械生成同义改写。

调用链是一条经阅读核对的路径，不一定每相邻步骤都是直接调用。回调注册与后续触发、事件发布订阅、依赖注入、接口分派、队列及 RPC 分开说明；跨进程时写出协议、序列化数据和提供者。静态图无法证明运行时目标时保留未解析项，不用同名搜索强行连线。不要把 `implements` 当成某次调用必然命中该类。

优先补齐入口装配、状态生命周期、关键算法、协议转换、并发与资源释放等重要或复杂实现，不只解释入口函数。文件符号、全局搜索和关系图标出“已讲解”，提供只看已有讲解的搜索入口。函数原有注释若为英文或中英混合，结合实现提供中文解读并保留原文对照；纯中文难懂时解释其语义。原注释与实现不一致要指出，不把过时注释翻译成事实。默认先讲解用户最常需要追踪的运行路径，再补失败恢复、状态管理和关键扩展边界。为其余模块提供真实索引入口，明确哪些已有深入分析、哪些只有自动索引。复用旧分析前核对当前版本与源码，不把旧调用链直接套入新版本。

## 入口与文件阅读顺序

默认打开由启动脚本、包入口或可执行文件配置确认的主入口函数，提供回到主入口的按钮。不要把容易展示的底层函数当成整个程序入口。调用链每个重要步骤都应有对应的短摘要和详细讲解；摘要直接说明“这个函数做什么”，不用标题的同义改写。重要代码文件开头提供职责、主要声明和建议阅读顺序；未人工分析的文件只显示明确标识的自动结构摘要。

## 关键文档的中文理解

优先选择入口 README、安装和第一次使用说明，以及主调用链相关的核心接口文档。逐份完整阅读，提供中文概要与完整正文译文，保留原文对照。概要说明用途、前置条件、读完能完成什么，以及接下来读哪份文档或源码。译文不是摘要；不要用几个中文要点冒充全文翻译。长文尚未完成时明确范围，用户只要求关键文档时不扩大成全仓翻译。

命令、代码块、标识符和协议字段保留原样，在代码块外补中文说明。原文和实现冲突时，在概要中指出依据，译文不悄悄改写原意。译文绑定原文件 SHA-256；原文变化后须复核，否则构建拒绝旧译文。仅在目标项目保存译文，不把项目名、案例和路径写入技能资产。页面提供“中文概要 / 中文译文 / 原文 / 原始文本”，关键文档可从统一搜索入口进入；文档内容按不可信文本处理，不执行 HTML 或脚本。

## 构建工作台

```sh
node <skill-directory>/scripts/build.mjs \
  --root <repository> \
  --analysis <repository>/source-guide/analysis.json \
  --out <repository>/source-guide/dist
```

可选 `--config` 指定目标仓库内 tsconfig，`--compiler` 指定兼容编译器模块的绝对路径。不要为执行分析而启动项目服务或使用真实模型密钥。输出包含完整可读文本快照，分享前确认源码允许分享；构建器排除常见凭证路径，不能将此宣称为完整秘密扫描。

工作台需保留文件树、当前文件符号、全局文件/符号/文本搜索、标签页、前后位置、书签、定义跳转、引用位置、调用者与调用目标、可缩放局部图、类接口关系与导入关系。点击图与关系应定位同一条源码证据；函数声明上方只展示一至两句摘要，点击“详细讲解”展开右侧面板；面板被隐藏或处于窄屏时也要能直接打开。摘要不插入函数体，不改变源码行号或复制结果。只读代码采用行号、语法着色、当前符号高亮、搜索与折叠；有夜间模式、全屏和可调整面板。

调用图默认只展示局部关系，保持节点实际像素字号，不为塞入全部引用而缩小到无法阅读。更多节点通过滚动、分批展开和切换中心查看；显示截断范围，完整位置仍可从关系列表进入。展开后字号不得下降。

运行脚本测试，并在实际项目用浏览器检查：同名函数不会混淆，别名导入能跳到真实声明，调用目标与调用位置入口不同，回调/接口/未知目标标签准确，代码中的特殊 HTML 文本不执行，完整源码和说明不串文件。检查全文搜索中断、图节点上限、窄屏、主题刷新、后退和代码跳转后的行号。索引未解决的边界写进交付说明。

更新时重新生成索引，校验人工讲解锚点，阅读改变的实现后再改解释。不要修改被分析项目的产品源码。交付网站路径、复现命令、已讲解路径及静态分析限制；通用资源留在技能仓库，项目案例与生成站点留在目标项目。
